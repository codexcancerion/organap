# `src/components/navigation/` — Chrome & Navigation Components

Persistent navigation components following the Voxsels 3-pane edge layout:
- `navbar.tsx`: Header navbar with edge-aligned alignment in auth mode, mobile drawer, and quick links.
- `sidebar.tsx`: Collapsible left-edge docked navigation sidebar with hidden scroller and role-based links.
- `right_panel.tsx`: Collapsible right-edge docked contextual panel with preset cycling, resizer handle, and dynamic page-driven render slots.
- `auth_shell.tsx`: 3-pane layout shell orchestrating edge-docked sidebar, centered content area, and edge-docked right panel.
