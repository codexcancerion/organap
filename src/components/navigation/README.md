# `src/components/navigation/` — Chrome & Navigation Components

Persistent navigation components following the Voxsels layout:
- `navbar.tsx`: Header navbar with edge-aligned alignment in auth mode, mobile drawer, and quick links.
- `sidebar.tsx`: Collapsible left-edge docked navigation sidebar with hidden scroller and role-based links.
- `right_panel.tsx`: Collapsible right-edge docked contextual panel with preset cycling, resizer handle, and dynamic page-driven render slots (preserved for future activation).
- `auth_shell.tsx`: Authenticated app layout shell orchestrating the left edge-docked sidebar and centered content area.
