# `src/components/ui/` — Shared UI Primitives

Reusable UI primitives used across $\ge 2$ features.
- `logo.tsx`: Brand mark & home navigation.
- `theme-switch.tsx`: Dark/light mode switcher.
- `cookie_consent.tsx`: Essential cookie banner.
- `proposal_status_chip.tsx`: Standardized status chip for event proposals across proposals, organizations, and venues.
- `confirm_delete_modal.tsx`: Shared destructive-action confirmation modal used across institutional features.
- `danger_zone_section.tsx`: Shared Danger Zone block for entity Settings modals.
- `image_crop_uploader.tsx`: Shared interactive square image uploader with drag-to-pan, HeroUI Slider zoom cropping, and offscreen WebP/JPEG compression.
- `catalog_filter_dropdown.tsx`: Shared toolbar filter control rendering a single HeroUI `Select` dropdown for one filter or a unified `Popover` filter menu when multiple filters apply.
