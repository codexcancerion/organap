# `src/components/` — Shared UI Primitives and Shells

Components in this directory are shared across $\ge 2$ features.
- `layout/`: Page sections and layout wrappers.
- `navigation/`: Navbar, Sidebar, AuthShell, Footer.
- `ui/`: Logo, ThemeSwitch, CookieConsent.

Feature-specific components belong exclusively inside `src/features/<feature>/components/`.
